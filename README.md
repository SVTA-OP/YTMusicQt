# YTMusic Desktop Client

A snappy, native-feeling YouTube Music client built with PyQt6.

## Features

- 🎵 **Full playback** — streams audio via yt-dlp, no browser required
- 🔄 **Google Account sync** — history, liked songs, and playlists pulled from your real YTM account
- 📋 **Playlist management** — browse, play, and queue any of your playlists
- 🎨 **Now Playing Dashboard** — large album art and current queue view, auto-switches when playing
- 📚 **Library View** — centralized access to all your playlists
- ⚡ **Async everything** — all network calls run on background threads; the UI never freezes
- 🎨 **System theme** — inherits your OS color scheme (dark/light mode, accent colors)
- 🎮 **Discord RPC** — shows currently playing track in Discord (optional)
- ⌨️ **Keyboard shortcuts** — Space (play/pause), Ctrl+← / Ctrl+→ (prev/next), Ctrl+F (search)
- 🔀 **Shuffle & Repeat** — per-queue shuffle, repeat-one, repeat-all
- 📦 **Prefetch** — next track's stream URL is fetched in the background while you're listening

## Installation

### 1. Install Python dependencies

```bash
pip install -r requirements.txt
```

> **Linux note:** You may also need system multimedia packages:
> ```bash
> # Ubuntu / Debian
> sudo apt install python3-pyqt6 gstreamer1.0-plugins-good gstreamer1.0-plugins-bad
>
> # Fedora
> sudo dnf install python3-qt6 gstreamer1-plugins-good gstreamer1-plugins-bad-free
> ```

### 2. Run the app

```bash
python main.py
```

## Authentication

YouTube Music requires you to be signed in. The app supports two methods:

### Method A — Browser Request Headers (Recommended, no API key needed)

1. Open [music.youtube.com](https://music.youtube.com) in your browser and sign in
2. Open DevTools → Network tab (F12)
3. Play any song, then right-click the first request to `music.youtube.com`
4. Choose **Copy → Copy request headers**
5. Paste into the app's Sign In dialog

Your credentials are saved to `~/.config/ytmusic-desktop/browser.json` and reused on future launches.

### Method B — Existing auth file

If you already have a `browser.json` or `oauth.json` generated by ytmusicapi, use the "Existing Auth File" tab in the sign-in dialog.

## Discord RPC Setup

1. Go to the [Discord Developer Portal](https://discord.com/developers/applications) and create a new application
2. Copy the **Application ID**
3. Open `app/workers/discord_rpc.py` and replace `APP_ID = "1234567890123456789"` with your ID
4. (Optional) Upload assets named `ytmusic_logo`, `playing`, and `paused` to the app's Rich Presence assets

If Discord is not running or `pypresence` is not installed, the app runs normally — RPC is fully optional.

## Performance Notes

- All API calls run on a `QThreadPool` (4 workers max) — zero UI blocking
- Thumbnails are fetched with 40ms stagger to avoid request floods
- Next track stream URL is prefetched 2 seconds into the current track
- Track list uses a custom `QStyledItemDelegate` for O(visible rows) rendering
- Window geometry is persisted via `QSettings`

## Troubleshooting

**No audio on Linux?**
Make sure GStreamer plugins are installed (see Installation above). You can test with:
```bash
python -c "from PyQt6.QtMultimedia import QMediaPlayer; print('OK')"
```

**Authentication errors?**
Delete `~/.config/ytmusic-desktop/browser.json` and re-run to get a fresh auth dialog.

**yt-dlp fails?**
Update it: `pip install -U yt-dlp`. YouTube occasionally changes their API and yt-dlp updates frequently.

**Discord RPC not showing?**
- Make sure Discord is running before the app starts
- Verify your App ID in `discord_rpc.py`
- Check that "Display current activity as a status message" is enabled in Discord settings
